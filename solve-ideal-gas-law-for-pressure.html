Solving PV = nRT for pressure

P = nRT / V

Start from PV = nRT and divide both sides by whatever is sitting next to P. Everything else stays where it is. 310 K is body temperature, which is where this one usually turns up in physiology questions.

Worked example

0.500 mol of gas is sealed in a 10.0 L vessel at 310 K. What is the pressure?

P = nRT / V
P = (0.500 mol x 0.08206 L·atm/mol·K x 310 K) / 10.0 L
P = 12.719 / 10.0
P = 1.27 atm

Why the rearrangement works

PV = nRT is one equation with four variables and a constant, so knowing any three gives you the fourth. To isolate P, divide both sides by everything that shares its side of the equals sign. Nothing else moves, and no term changes sign, because there is no addition anywhere in the equation. That is why all four rearrangements look so similar.

The same problem in different units

The same vessel, but the answer wanted in mmHg, so R = 62.36 L·mmHg/mol·K.

P = nRT / V
P = (0.500 mol x 62.36 L·mmHg/mol·K x 310 K) / 10.0 L
P = 9665.8 / 10.0
P = 967 mmHg

Same pressure, different ruler. 967 mmHg is 1.27 atm, since one atmosphere is 760 mmHg.

Which R to use

R only looks like several different constants because it carries units. Pick the one that matches the units you already have, and do not convert anything afterwards.

RUnitsUse when
0.08206L·atm / mol·Kpressure in atm, volume in litres
8.314J / mol·Kpressure in pascals, volume in cubic metres
62.36L·mmHg / mol·Kpressure in mmHg or torr

Where this goes wrong

Temperature must be in kelvin. Celsius is the single most common reason an ideal gas answer comes out wrong, and it is silent: the arithmetic still works, the number is just false. Add 273.15.

R has to match your units. Using 0.08206 with pressure in kilopascals gives an answer that is out by a factor of about a hundred.

Volume in litres, not millilitres, when you are using 0.08206. A 250 mL flask is 0.250 L.

The other rearrangements

  • n = PV / RT, for moles
  • V = nRT / P, for volume
  • T = PV / nR, for temperature
