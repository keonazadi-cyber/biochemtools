The charts are yours to use

Every downloadable chart on this site is released under a Creative Commons Attribution 4.0 International licence. In plain terms: print them, hand them out, put them on a course page, add them to a library guide, translate them, or cut them up and build something better. Commercial use is fine too. The only thing asked in return is credit.

What the licence covers

The twelve printable charts, in both the dark and the print-friendly versions, and the reference tables they are drawn from. The site's code and page designs are not included.

How to credit it

Anything that names the source and points back is fine. If you want something to paste:

Chart by Biochemtools, licensed CC BY 4.0.

For a printed handout, "Biochemtools (biochemtools.com), CC BY 4.0" is enough. Each chart also carries the licence in its own footer, so it stays attributed even when the image gets separated from the page it came from.

For librarians and instructors

This is an open educational resource, so it can sit on an OER guide rather than only on a general links page. Nothing on the site is paid, there are no accounts, and there is no advertising on the chart pages. If a chart would be more useful to your students with something added, changed or corrected, please say so. Readers have improved these charts several times and one of them is credited on the inhibition chart by name for exactly that.

If you find a mistake

Tell me and it gets fixed, usually the same day. Every number on these charts is checked against the data behind it when the chart is built, so a chart that contradicts its own source will not render at all. That catches a lot, but it does not catch everything, and a real person reading it carefully still catches more.
