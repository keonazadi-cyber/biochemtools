# Chart build scripts

Every downloadable chart in `/downloads` is generated by one of the `make_*_guide.py`
scripts here. They are kept in the repo because they were not, and it cost us: the
data they read used to sit in a temp directory that got cleaned, and once it was gone
most charts could not be rebuilt at all. A chart you cannot rebuild is a chart whose
mistakes you cannot fix.

## How it fits together

- `chartdata.py` pulls each dataset straight out of the tool page that owns it, so a
  chart can never disagree with the page it came from. It also strips inline HTML,
  turning `H<sup>+</sup>` into `H⁺` and flattening subscripts, since Pillow draws text
  and knows nothing about tags.
- `aastructures.py` draws the 20 amino acid structures with RDKit. It checks each one
  against the molecular weight, net charge and CIP configuration the page publishes
  before drawing anything. That check is what caught alanine being drawn as D-alanine
  under a footer promising the L-isomer.
- `lightmode.py` holds both palettes. Every script takes `--light` for the print version.
- `deploy_charts.py` copies the built images into `/downloads` under their public
  names, which used to be a mapping somebody had to remember.

## Rebuilding

```
python3 aastructures.py                 # only needed if a structure changes
for f in make_*guide*.py; do
  python3 "$f" && python3 "$f" --light
done
python3 deploy_charts.py
```

The scripts assert their own claims. If a chart says "4 of the 6 saturate", that
number is counted from the data at build time, and the build fails rather than
printing something untrue.
